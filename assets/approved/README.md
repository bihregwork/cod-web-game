# Approved Visual Assets

Эта папка хранит только утвержденные изображения проекта.

## Правило

- Промежуточные варианты остаются в рабочих папках: `assets/technical-preview`, `assets/source-previews`, `assets/items`, `assets/concepts`.
- После явного принятия заказчиком финальная версия копируется сюда.
- Если у изображения появляется новая утвержденная версия, она добавляется сюда с понятным именем и фиксируется в `docs/PROJECT_LOG.md` и `docs/DECISIONS.md`.

## Структура

- `screens/desktop/` - финальные desktop mockup-экраны.
- `screens/mobile/` - финальные mobile mockup-экраны.
- `characters/` - утвержденные runtime-ассеты героини.
- `concepts/` - утвержденные концепты героини и Car Mode.
- `backgrounds/` - утвержденные фоны.
- `items/` - утвержденные игровые предметы.
- `ui-icons/` - утвержденные UI-иконки и референсы для кнопок.
