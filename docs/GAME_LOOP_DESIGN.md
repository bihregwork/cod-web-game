# Game Loop Design / Игровой цикл

Дата создания: 2026-07-21
Статус: Draft for Design

## Цель

Спроектировать поведение игрового цикла, состояний игры, предметов и столкновений перед Environment Setup и Development.

## Уже принято

- Стартовые жизни: 3.
- Игра идет, пока у игрока есть жизни.
- Уровень сложности: 1-40.
- Рост сложности идет только по очкам: +1 уровень за каждые 200000 очков.
- Рост сложности по времени отключен.
- Основная зона ловли: большой кошелек героини.
- В режиме машины предметы также попадают в кошелек героини.
- Игра работает через `requestAnimationFrame`.

## Состояния игры

- `idle`
- `playing`
- `paused`
- `carMode`
- `gameOver`
- `leaderboard`

## Игровой цикл

На каждом кадре игра должна:

- считать прошедшее время;
- обновлять уровень сложности;
- создавать новые предметы по вероятностям;
- двигать падающие предметы вниз;
- двигать героиню по вводу игрока;
- проверять столкновения предметов с кошельком;
- проверять предметы, ушедшие ниже экрана;
- обновлять HUD;
- рисовать новый кадр.

## Поведение состояний

| Состояние | Поведение |
|---|---|
| `idle` | Фон, героиня, HUD, кнопка `Старт`, предметы не падают |
| `playing` | Основная игра |
| `paused` | Все движение и таймеры заморожены |
| `carMode` | Машина активна, скорость выше обычного режима, бензин убывает |
| `gameOver` | Предметы остановлены, показывается итог и сохранение результата |
| `leaderboard` | Игра ставится на паузу, открывается топ-10 |

## Hitbox кошелька

- Ловит не вся героиня, а именно большой кошелек.
- У кошелька отдельный прямоугольный hitbox.
- Hitbox кошелька должен быть примерно на 10-15% больше видимого кошелька, чтобы ловля ощущалась честной.
- Если предмет пересек hitbox кошелька, он считается пойманным.
- В режиме машины hitbox остается у кошелька, а не у корпуса машины.
- Границы горизонтального движения считаются по прямоугольнику кошелька: героиня или машина могут частично уходить за край экрана, пока hitbox кошелька остается внутри игрового поля.
- Высота обычной героини синхронизирована с высотой `Car Mode`, а размеры прямоугольника кошелька одинаковы в двух режимах.
- После review-правок активная зона кошелька зафиксирована в размерах: desktop `150 x 105 px`; mobile `170 x 135 px`. На desktop зона увеличена по высоте на `5 px` вверх относительно прежней высоты `100 px`.
- Для desktop активная зона кошелька сдвинута на `5 px` вправо относительно предыдущего положения; mobile-положение оставлено без изменения.

## Hitbox предметов

- У предмета прямоугольный hitbox.
- Для мелких предметов hitbox может быть немного больше визуала.
- Для крупных предметов мебели hitbox должен быть немного меньше визуала, чтобы касание краем не ощущалось несправедливым.
- Для договора hitbox немного увеличен, потому пропуск договора снимает жизнь.

## Ловля предметов

| Предмет | При ловле |
|---|---|
| Купюра | +очки по номиналу |
| Зеркало | +10000 |
| Прихожая | +20000 |
| Кухня | +50000 |
| Договор | +100000 |
| Налог | -50000, счет не ниже 0, комичная реакция |
| Штраф | -1 жизнь, комичная реакция |
| Колесо, двигатель, корпус | Прогресс сборки машины |
| Канистра | +20 л бензина до лимита 60 л |

## Пропуски

- Предмет считается пропущенным, если он полностью ушел ниже нижней границы игрового поля.
- Пропущенные купюры, налог и штраф просто исчезают без штрафа.
- Пропущенная мебель, запчасти машины и канистра бензина увеличивают счетчик пропусков.
- За 3 таких пропуска снимается 1 жизнь, затем счетчик пропусков сбрасывается.
- Пропущенный договор снимает 1 жизнь.
- Если после потери жизни у игрока 0 жизней, игра переходит в `gameOver`.

## Пауза

- Кнопка паузы переводит игру в `paused`.
- Клавиша `Пробел` запускает игру из начального/конечного состояния.
- Во время игры клавиша `Пробел` ставит игру на паузу.
- В паузе клавиша `Пробел` продолжает игру.
- В паузе не падают предметы.
- В паузе не тратится бензин.
- В паузе не растет таймер сложности.
- Повторное нажатие продолжает игру.
- Открытие таблицы рекордов переводит игру в `leaderboard` и фактически ставит игру на паузу.

## Game Over

- `gameOver` наступает при 0 жизней.
- Падение предметов останавливается.
- На экране показываются:
  - итоговый счет;
  - поле имени;
  - кнопка сохранения результата;
  - топ-10;
  - кнопка сыграть снова.
- Если результат ниже личного рекорда `playerId`, API не обновляет топ-10.

## Car Mode

- Режим включается, когда собраны 4 колеса, двигатель, корпус и бензин больше 0.
- Героиня отображается в машине, но кошелек виден.
- Скорость горизонтального движения выше обычного режима; базовый runtime-баланс v1: обычная героиня `220 px/s`, `Car Mode` `340 px/s`.
- При увеличении сложности скорость горизонтального движения героини без авто и в `Car Mode` растет по диапазонам от базовой скорости: уровни `1-20` - `+1%` за уровень, уровни `21-40` - `+2%` за уровень.
- Бензин уменьшается на 1 л каждую секунду.
- Максимальный запас бензина: 60 л.
- `Car Mode` длится, пока не закончится бензин.
- Запас бензина не может быть больше 60 л в любой момент.
- Когда бензин достигает 0, режим машины выключается.
- Машина не защищает от налога, штрафа и пропущенного договора.
- Во время активного режима машины запчасти не падают.
- Во время активного режима машины бензин может падать.
- Пойманная во время `Car Mode` канистра может продлить текущий режим, но запас бензина остается ограничен 60 л.
- Если в `Car Mode` бензина 20 л или меньше и за последние 15 секунд не появлялась канистра, следующая подходящая генерация предмета принудительно дает канистру.

## Fairness

- После потери жизни включается короткая защита `700 мс` от повторного мгновенного списания жизни.
- Защита нужна, чтобы один кадр или плотное скопление предметов не сняли несколько жизней сразу.
- Защита применяется к событиям потери жизни: пойманный штраф, третий обычный пропуск, пропущенный договор.
- Если после потери жизни у игрока стало `0` жизней, игра сразу переходит в `gameOver`, а обработка предметов в текущем кадре останавливается.

## Основные системы

- управление героиней;
- генерация падающих предметов;
- движение предметов;
- проверка столкновения с кошельком;
- обработка пропусков;
- начисление очков;
- снятие жизней;
- рост сложности;
- сборка машины;
- расход бензина;
- окончание игры;
- сохранение результата.

## Development clarification: правила пропусков v1

Дата: 2026-07-22

- Пропуск налога или штрафа не наказывает игрока.
- Пропуск одного договора сразу снимает 1 жизнь.
- Пропуск купюры не влияет на счетчик пропусков.
- Пропуск мебели, детали машины или канистры бензина увеличивает счетчик пропусков.
- За 3 таких пропуска снимается 1 жизнь, затем счетчик пропусков сбрасывается.
- Счетчик пропусков отображается слева под HUD в формате `Пропуски 0/3`.
