# Screen Flow / Экраны и переходы

Дата создания: 2026-07-21
Статус: Accepted for current Design block

## Цель

Спроектировать экраны и состояния интерфейса v1.

## Уже принято

- Отдельный стартовый экран не нужен.
- Игра стартует с основного игрового экрана по кнопке "Старт".
- Интерфейс должен работать на компьютере и телефоне.
- На мобильном устройстве управление героиней выполняется перетаскиванием.
- Таблица рекордов показывает топ-10.

## Основной игровой экран

Должен включать:

- игровое поле;
- главную героиню в деловом костюме с большим кошельком;
- падающие предметы;
- HUD со счетом и жизнями;
- индикатор сборки машины;
- индикатор бензина;
- кнопку "Старт";
- кнопку паузы;
- кнопку рестарта;
- доступ к таблице рекордов.

## Принятая структура основного экрана

### Фон

- Desktop-фон: `docs/references/visual/tomsk-collage-desktop.png`.
- Mobile-фон: `docs/references/visual/tomsk-collage-mobile.png`.
- Фон занимает весь экран.
- Игровое поле и HUD располагаются поверх фона.
- Верхняя часть экрана используется как зона падения предметов.
- Нижняя часть экрана используется как зона движения героини.
- На игровое поле можно добавить легкий прозрачный слой для читаемости предметов и HUD, не закрывая фон.

## HUD машины

Состав:

```text
[колесо 1][колесо 2][колесо 3][колесо 4] [двигатель] [корпус]  Бензин: 40 л
```

| Состояние | Отображение |
|---|---|
| Пустой слот | Серый контур слота |
| Собранная деталь | Цветная иконка именно этой детали |
| Машина собрана, бензина нет | Статус `Нужен бензин` |
| Машина активна | Индикатор машины подсвечен, бензин убывает |

Поведение:

- Пока деталь не собрана, слот виден как серый контур.
- Когда деталь поймана, соответствующий слот заменяется цветной иконкой этой детали.
- Колеса заполняются по одному: 1/4, 2/4, 3/4, 4/4.
- Двигатель и корпус имеют отдельные слоты.
- Если все детали собраны, но бензина `0 л`, рядом появляется статус `Нужен бензин`.
- Если машина активна, весь блок машины подсвечивается, а бензин уменьшается каждую секунду.
- Если бензин достиг `0 л`, подсветка пропадает, машина больше не активна.

## Таблица рекордов

- Таблица рекордов открывается как модальное окно поверх игры.
- На экране Game Over показываются итоговый счет, ввод имени, сохранение результата и топ-10.

## Состояния интерфейса

- Idle: игра еще не началась, видна кнопка "Старт".
- Countdown: короткий отсчет перед началом падения предметов.
- Playing: игра идет.
- Car Mode: активен машинный бонус.
- Paused: игра поставлена на паузу.
- Leaderboard: показан топ-10.
- Game Over: закончились жизни, можно ввести имя и сохранить результат.

## Принятая модель экранов и состояний

| Состояние | Что видит игрок | Основные элементы | Переходы |
|---|---|---|---|
| `Idle` / до старта | Основной игровой экран уже виден, но предметы не падают | Фон Tomsk collage, героиня с кошельком внизу, счет `0`, жизни `3`, HUD машины пустой, кнопка `Старт`, кнопка рекордов | `Старт` -> `Countdown`; `Рекорды` -> `Leaderboard` |
| `Countdown` / отсчет | Быстрый стартовый отсчет | Большие числа `3`, `2`, `1`; HUD уже виден; управление можно не блокировать | После отсчета -> `Playing` |
| `Playing` / игра идет | Основной игровой процесс | Падающие предметы, счет, жизни, пауза, рестарт, рекорды, HUD машины справа, героиня ловит кошельком | `Пауза` -> `Paused`; `Рекорды` -> `Leaderboard`; собрана машина + есть бензин -> `Car Mode`; жизни `0` -> `Game Over` |
| `Car Mode` / машина активна | Вместо обычной героини показывается героиня в желтом седане | Car-mode asset, подсветка HUD машины, убывающий бензин, скорость выше обычного режима, кошелек остается зоной ловли | Бензин закончился -> `Playing`; `Пауза` -> `Paused`; жизни `0` -> `Game Over` |
| `Paused` / пауза | Игра заморожена | Полупрозрачное затемнение, кнопки `Продолжить`, `Рестарт`, `Рекорды` | `Продолжить` -> прежнее состояние; `Рестарт` -> `Idle`; `Рекорды` -> `Leaderboard` |
| `Leaderboard` / рекорды | Модальное окно топ-10 | Список лучших результатов, имя игрока, текущий лучший результат игрока, кнопка закрытия | Закрыть -> прежнее состояние; если открыто во время игры, игра остается на паузе |
| `Game Over` | Финал попытки | Итоговый счет, поле имени, кнопка `Сохранить результат`, топ-10, кнопка `Играть снова` | `Играть снова` -> `Idle`; после сохранения обновляется top-10 |

## Принятая логика интерфейса

- Основной экран один: игра не уходит на отдельные страницы, состояния открываются поверх игрового поля.
- `Idle` не выглядит как отдельное меню: игрок сразу видит будущую игру, героиню, HUD и кнопку `Старт`.
- `Leaderboard` и `Paused` работают как модальные состояния поверх игры.
- При открытии рекордов во время игры таймеры, падение предметов, бензин и рост сложности останавливаются.
- `Car Mode` не отдельный экран, а визуальное состояние игрового поля: меняется персонаж, включается подсветка машины и расход бензина.
- В `Game Over` игрок вводит имя профиля: новое имя создает новый локальный `playerId`, существующее имя использует прежний `playerId`.
- `Старт` размещается над нижней частью экрана так, чтобы не закрывать героиню.
- `Пауза` отображается компактной иконкой в HUD.
- Клавиша `Пробел` запускает игру из начального/конечного состояния, во время игры ставит на паузу, а в паузе продолжает игру.
- `Рестарт` доступен всегда, но во время активной игры требует короткого подтверждения.
- В `Game Over` можно показывать короткую комичную фразу по результату.
- При активации `Car Mode` показывается короткая вспышка или плашка `Машина собрана!` примерно на 1 секунду.

## Поведение модальных состояний

- При `paused` все движение, таймеры, бензин и рост сложности заморожены.
- При `leaderboard` игра фактически стоит на паузе, чтобы игрок не терял предметы за просмотром рекордов.
- При `gameOver` предметы остановлены, показываются итоговый счет, поле имени, сохранение результата, топ-10 и кнопка сыграть снова.
