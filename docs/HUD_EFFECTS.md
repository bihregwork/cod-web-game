# HUD & Effects / HUD и эффекты

Дата создания: 2026-07-21
Статус: Accepted for current Design block

## Цель

Зафиксировать визуальную модель HUD и эффектов v1: какие элементы показываются, какие состояния у них есть, и что реализуется кодом, а что использует готовые ассеты.

## HUD

| Блок | Что показываем | Состояния |
|---|---|---|
| Счет | `Очки: 000000` | обычный рост, короткий pop-up при начислении или штрафе |
| Жизни | 3 иконки сердца | полное сердце, потеря жизни с коротким красным flash |
| Кнопки | старт, пауза, рестарт, рекорды | делаются кодом/lucide/CSS, без отдельных растровых картинок |
| HUD машины | 4 колеса, двигатель, корпус, бензин | пустой слот, собранная деталь, нужен бензин, активный режим |
| Бензин | `Бензин: 0/60 л` + маленькая шкала | 0, 1-20, 21-40, 41-60 |
| Статус машины | короткая подпись | `Собери машину`, `Нужен бензин`, `Car Mode` |

## HUD машины

| Состояние | Визуал |
|---|---|
| Деталь не собрана | серый слот-контур |
| Деталь собрана | цветная мини-иконка детали |
| 4 колеса собраны | 4 заполненных слота колес |
| Машина собрана, бензина 0 | статус `Нужен бензин` |
| Машина собрана, бензин > 0 | включается `Car Mode` |
| Машина активна | желтая подсветка HUD, бензин убывает |
| Бензин 60 л | шкала полная, новые канистры не падают |

## Эффекты

| Событие | Эффект |
|---|---|
| Пойман полезный предмет | короткая вспышка у кошелька + `+очки` |
| Поймана купюра | зеленовато-золотой pop-up |
| Поймана мебель | более крупный pop-up, легкий bounce |
| Пойман договор | золотая вспышка + `+100000` |
| Пропущен договор | красная вспышка + `-1 жизнь` |
| Пойман налог | красный штамп-эффект + `-50000` |
| Пойман штраф | красный flash + потеря сердца |
| Поймана запчасть | слот машины заполняется с коротким pulse |
| Поймана лишняя деталь | маленькая фраза `Лишняя деталь!` без очков |
| Машина собрана | плашка `Машина собрана!` на 1 секунду |
| `Car Mode` старт | желтая вспышка, смена героини на машину |
| Бензин закончился | подсветка гаснет, возврат к обычной героине |

## Что делаем кодом/CSS/canvas

- слоты;
- шкала бензина;
- подсветка;
- pop-up очков;
- вспышки;
- shake;
- кнопки;
- текстовые плашки.

## Принцип v1

Отдельные картинки для HUD/effects сейчас не генерируются. Визуальная модель фиксируется в документах, а эффекты реализуются кодом на этапе Implementation.

Причина: кодовые эффекты проще контролировать, они лучше масштабируются под desktop/mobile и не плодят лишние растровые элементы.

## Правило фиксации

Изменения HUD/effects сначала обсуждаются в чате и записываются сюда только после явного принятия заказчиком.
